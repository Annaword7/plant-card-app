# plant-card-app

Генератор карточек растений и SEO-описаний для питомника «Роза Ругоза».

## Запуск

```bash
npm install
npm run dev          # фронтенд на Vite
npm run deploy       # сборка + express на :3001
```

Нужна переменная `ANTHROPIC_API_KEY`.

## Промпты по типам растений

Промпты и наборы характеристик живут отдельно от кода и правятся прямо в интерфейсе —
блок «⚙ Промпты по типам растений» над шагом 1.

Для каждого типа (роза, многолетник, плодовое дерево, плодовый кустарник, хвойное,
декоративный кустарник, другое) настраивается:

- **специфика типа** — что учесть в описании и какие темы взять в FAQ;
- **характеристики** — список с иконкой, подсказкой для модели и признаком «показывать звёздами».
  От него зависят и параметры на картинке (шаг 1), и таблица характеристик в описании.

Общие для всех типов — промпт описания, промпт подбора характеристик и фраза-дисклеймер
в конце описания. Свои типы добавляются кнопкой «+ Добавить тип» (клонируется текущий),
заводские можно вернуть кнопкой «Сбросить».

Заводские значения: [prompts.defaults.js](prompts.defaults.js).
Сборка финальных промптов: [prompt-builder.js](prompt-builder.js).

### Где хранятся правки

JSON-файл `prompts.json`. Путь выбирается так:

1. `RAILWAY_VOLUME_MOUNT_PATH` — Railway сам задаёт эту переменную для подключённого тома;
2. `PROMPTS_DIR` из переменных окружения;
3. уже смонтированный `/data`;
4. `./data` рядом с кодом — только как запасной вариант.

**На Railway нужно подключить Volume** (Service → Settings → Volumes, mount path `/data`),
иначе правки пропадут при следующем деплое. Пока тома нет, редактор промптов показывает
предупреждение, а в логе при старте видно `внимание: не Volume`.
